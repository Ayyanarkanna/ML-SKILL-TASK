# 📊 Online Learning Student Performance Analysis

## 📌 Project Overview

This project analyzes student engagement and academic performance in an online learning environment. Using data visualization and machine learning techniques, the project identifies patterns between student engagement levels and course outcomes.

The study explores how factors such as engagement levels influence student success and builds a predictive model to classify student performance.

---

## 🚀 Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Student engagement analysis
* Data visualization using Seaborn and Matplotlib
* Machine Learning model using Random Forest Classifier
* Performance evaluation with:

  * Accuracy Score
  * Classification Report
  * Confusion Matrix

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

---

## 📂 Dataset

The project uses an online learning dataset (`online.csv`) containing information about:

* Student engagement levels
* Scores and performance metrics
* Final course results
* Pass/Fail indicators
